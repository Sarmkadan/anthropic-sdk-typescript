# Contributing

We welcome contributions to the Claude SDK for TypeScript.

## Getting Started

1. Fork and clone the repository.
2. Install dependencies: `yarn`.
3. Build the project: `yarn build`.

## Development

- **Modifying Code**: Please ensure your changes are consistent with the existing style.
- **Testing**: Run tests using `./scripts/test`. Ensure all tests pass.
- **Linting**: Run `yarn lint` to check for formatting and lint issues. Fix with `yarn fix`.

## Submitting Changes

Please open a Pull Request with a clear description of your changes and the problem they solve. All PRs should pass CI checks.
